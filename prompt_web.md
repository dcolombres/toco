[FUNCIONALIDADES TÉCNICAS REQUERIDAS]
Formulario de registro: Debe enviar los datos a una hoja de cálculo de Google Sheets (Google Forms integrado o API directa). Al enviar, mostrar mensaje de éxito: "¡Listo! En las próximas 24 horas te escribimos por WhatsApp."

Diseño responsive: Debe verse perfecto en celular, tablet y escritorio.

Botón de WhatsApp flotante: Ícono verde fijo en la esquina inferior derecha que abre un chat predefinido con el mensaje: "Hola, quiero ser revendedor TOCO"

Animaciones suaves: Efecto fade-in al hacer scroll para cada sección.

Enlaces internos: Los botones "Cómo funciona" y del footer deben hacer scroll suave hasta la sección correspondiente.

Carga rápida: Optimizar imágenes y usar lazy loading.

[TECNOLOGÍAS SUGERIDAS PARA EL AGENTE]
Podés usar cualquier stack, pero recomiendo:

HTML/CSS/JS puro (más simple y rápido de desplegar)

O Tailwind CSS para agilizar el diseño

O React + Vite si se necesita más dinamismo

Integración con Google Sheets usando Google Apps Script o Formspree

Despliegue sugerido: Netlify, Vercel, o GitHub Pages (gratis)
